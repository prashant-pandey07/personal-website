FlowWrite — a writing application by Prashant Pandey

FlowWrite is Prashant Pandey’s writing application experiment, exploring rich documents, AI-assisted writing, history, and export.

By Prashant Pandey2026-10-05

A writing application I’m building to explore what a focused, flexible writing environment can be.

FlowWrite brings together a quiet writing canvas, rich document formatting, AI-assisted writing features, document history, search, and export workflows. Its editor uses a transparent text input with a rendered layer for formatted content. Documents can include code, tables, images, and other structured material.

I started FlowWrite because I wanted more control over how I write, organize, format, and export documents. Building it has given me practical questions to work through in interface design, document models, saving, import and export, and application architecture.

What I’m exploring

  • A calm writing interface with keyboard-first editing
  • Rich document content and code blocks
  • Local drafts, saving, and version history
  • AI-assisted correction and continuation
  • HTML and PDF export, with an optional native format

FlowWrite is a work in progress. This page describes the project as it currently stands; details may change as I build and learn.
