# Miss Minute To The End  —  sample script
var greeting = "Hello from the TVA!"
var loops    = 3

sequence intro {
  expression excited
  say $greeting for 3
  fx sparkle 6
}

0      background timeline
0.5    enter left
at 2 { call intro }

at 6 {
  repeat $loops {
    move dance
    wait 0.8
  }
  expression happy
}

+5    exit right

The Story

Inspired by the Sacred Timeline

Miss Minute To The End is a passion project born from love for the TVA universe in Loki Season 1. The character Miss Minutes — the cheerful clockwork mascot of the Time Variance Authority — captured imaginations worldwide. This project brings her to life in your browser.

The title "The Beginning Is the Ending" reflects both the circular nature of the TVA's Sacred Timeline and the creative philosophy behind this tool: every animation you script begins and ends in a loop of infinite creative possibility.

What started as an experiment with SVG procedural animation grew into a fully-featured studio with its own scripting language — because when you love a character enough, you build a whole programming environment to animate her.

Scripting Language

Write animations like code

The Miss Minutes scripting language is designed to be easy to learn but powerful enough for complex productions. Here's a taste of what you can write: 

# ── Variables & conditional logic ─────────────────────
var score = 8
var name  = "Miss Minutes"

at 2 {
  if $score > 7 {
    expression excited
    say "$name approves! Score: $score" for 3
    fx sparkle 8
  } elif $score > 4 {
    expression neutral
    say "Could be better…" for 2
  } else {
    expression sad
    say "Oh dear, sugar…" for 2
  }
}

All supported commands

expressionSet facial expression + optional auto-revert
moveBody animation (bounce, dance, wave…)
lookPoint eyes in any direction
say "text"Caption + automatic lip-sync
talkLip-sync without caption text
fxParticle effect with count control
enter / exitCharacter stage entries and exits
peekPeek in from side and retreat
walk / walkToMove character across stage
backgroundAnimated scene backgrounds + video
audioLoad and play audio files
audio.fadeSmooth volume fade over duration
blinkForce a manual blink cycle
leanTilt character body at angle
findTVA timeline search animation
waitPause block execution N seconds
if / elif / elseConditional branching logic
repeat / whileLoop structures with counter
sequence / callReusable named blocks
togetherRun commands in parallel
break / continueLoop control flow
endStop the entire animation
Workflow

How It Works

From first line of script to full-screen performance in four steps.

01

Write Your Script

Use the built-in editor with live syntax highlighting, auto-indent, error detection, and a command palette. No external tools needed.

02

Upload Media

Drag and drop audio or video files into the Media Library. They're instantly accessible in your script by filename.

03

Preview Live

Click Preview to watch your animation on the stage in real-time. Fix errors in the Problems panel and iterate instantly.

04

Play Full-Screen

Press Play for a cinematic 5-4-3-2-1 countdown and full-screen performance. Escape to stop at any time.
