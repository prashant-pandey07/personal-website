    Quick Reference

    ⏱ Timing

    5          → at 5 seconds
2.5        → at 2.5 sec
1:05       → 1 min 5 sec
+2         → 2s after prev line
at 3.5 {}  → block at 3.5s

    📦 Variables

    var x = 5
var msg = "Hello!"
var active = true
set x = $x + 1
say $msg for 2

    🔁 Loops

    repeat 3 {
  move bounce
  wait 1
}

var i = 0
while $i < 5 {
  fx sparkle
  set i = $i + 1
  wait 0.5
}

# break out of a loop
repeat 100 {
  fx sparkle
  wait 0.5
  if $done { break }
}

    🔀 If / Elif / Else

    if $x > 3 {
  expression excited
} elif $x > 1 {
  expression happy
} else {
  expression neutral
}

    🎯 Sequences

    sequence myGreet {
  expression happy
  move wave
  say "Hi there!" for 2
}

# Call it anywhere:
at 3 { call myGreet }

    ⚡ Together (parallel)

    together {
  move dance
  say "Watch me!" for 3
}
